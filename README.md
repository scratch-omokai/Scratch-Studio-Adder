# Scratch スタジオ一括操作

Scratch の1つの作品を、複数のスタジオへまとめて追加・削除する Chrome 拡張機能です。

## 機能

- 作品を複数のスタジオへ一括追加
- 作品を複数のスタジオから一括削除
- 「削除→追加」をスタジオごとに実行
- スタジオIDを複数指定
- 作品・スタジオのURLにも対応
- API操作間のクールタイムを設定
- クールタイムを最大50%ランダムに延長
- 処理の停止
- 進捗・結果ログの表示とコピー
- 設定の自動保存

## 使い方

1. Scratch にログインします。
2. Scratch のタブを開いた状態で拡張機能を開きます。
3. **作品ID（または作品URL）**を入力します。
4. 操作したい**スタジオID**を1行ずつ入力します。
5. クールタイムを設定します。
6. **「追加する」「削除する」「削除→追加」**のいずれかを実行します。

スタジオIDは数字だけでなく、スタジオURLも入力できます。

## クールタイム

APIを呼び出すたびに指定した時間待機します。

「ランダムに最大50%長くする」を有効にすると、指定時間に0〜50%のランダムな待機時間が追加されます。

## 注意

- Scratch にログインした状態で使用してください。
- `scratch.mit.edu` のタブが必要です。
- APIのエラーなどで3回連続して失敗すると処理を停止します。
- 削除時に404が返った場合、そのスタジオに作品がないものとしてスキップします。
- 「削除→追加」では、削除に失敗したスタジオへの追加は行いません。
- Scratch の仕様変更により動作しなくなる可能性があります。

## インストール

Chrome の拡張機能管理画面でデベロッパーモードを有効にし、**「パッケージ化されていない拡張機能を読み込む」**から `manifest.json` のあるフォルダーを選択してください。

## 技術情報

Manifest V3 を使用しています。

主なファイル:

- `manifest.json`：拡張機能の設定
- `background.js`：アイコンクリック時にサイドパネルを開く設定
- `sidepanel.html`：ユーザーインターフェース
- `sidepanel.css`：デザイン
- `sidepanel.js`：処理本体

Scratch APIへの操作は、ログイン中のScratchタブ上で実行されます。
